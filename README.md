# mu-chemtools
Methodist University - Chemistry Tools

## Physics projects

Each folder is a self-contained project: the app is its own `index.html`, with no build step and
no dependencies, so it opens directly or publishes on its own.

| Project | What it is |
| --- | --- |
| [circuit-diagram](circuit-diagram/) | Circuit Lab — draw a circuit, then read the voltmeter and ammeter live |
| [torque-balance](torque-balance/) | Torque Balance Lab — meterstick, hanger masses and an unknown mass |
| [work-power](work-power/) | Work & Power Lab — cart on an incline pulled by a hanging weight |
| [atwood-machine](atwood-machine/) | Atwood's Machine Lab — two masses over a pulley, timed by a photogate |

The hub at the repository root links to all four, and the older `physics/*.html` paths redirect to them.
